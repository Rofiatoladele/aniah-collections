# Aniah's Collection store

Files: index.html, style.css, script.js, config.js (your settings), products.js (your products), images/logo.png

1. Open config.js and set your WhatsApp number, bank details and owner PIN.
2. To add products: open the site, click "Owner login" in the footer, enter the PIN, add products and photos,
   then click "Download products.js" and replace the old products.js in this folder / on GitHub.
3. Host free with GitHub Pages: repo Settings > Pages > Deploy from branch > main > / (root).
